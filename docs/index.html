Swiss IBAN Validator

Kostenlose Chrome Extension zur Validierung von Schweizer IBAN-Nummern. Prüft Format, Prüfziffer und erkennt die Bank automatisch.

Chrome Web Store ERPLight.ch besuchen

Features

IBAN-Validierung

Prüft Schweizer IBAN-Nummern auf korrektes Format und gültige Prüfziffer nach ISO 13616.

Bank-Erkennung

Erkennt automatisch die Bank anhand der IID (Instituts-Identifikation) — über 200 Schweizer Banken hinterlegt.

QR-IBAN Support

Unterscheidet zwischen klassischen IBAN und QR-IBAN (IID 30000–31999) für die Schweizer QR-Rechnung.

Ein Open-Source-Projekt von ERPLight — Schweizer Rechnungssoftware für KMU und Freelancer.
